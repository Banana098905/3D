EMBED API

既存ページに canvas とスクリプトを追加して利用する設計です。HTTPSまたはローカルHTTPサーバーで配信してください。

<canvas id="world"></canvas> <script src="massive-engine.js"></script> <script> const engine = new MassiveEngine.Engine({ canvas: document.querySelector('#world'), count: 10000, gridCellSize: 0.60 }); </script>

API：start() / stop() / setCount(n) / setSpeed(n) / setGridCellSize(n) / getStats() / dispose()

Prototype 1.9：埋め込みAPIと基準シミュレーションを分離した概念実証。ライブラリ互換性・複数ブラウザ・長時間安定性は今後の検証対象。
