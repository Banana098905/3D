LIVE METRICS

EMBED API

<canvas id="world"></canvas>
<script src="massive-engine.js"></script>
<script>
  const engine = MassiveEngine.create({
    canvas: document.querySelector('#world'),
    count: 10000,        // 互換モード（粒子）
    gridCellSize: 0.60
  });
</script>

count を省略すると空のシーンから始まり、addBox() / addSphere() / InstancedMesh などで自由に構成できます。詳細は docs/API.md。
