# 既知の制限・対応ブラウザ

## 対応ブラウザ
- **必須**: WebGL 2（`canvas.getContext('webgl2')`）。`isSupported()` で判定できます。
- **動作確認済み**: Chromium（Playwright 同梱）+ SwiftShader（ソフトウェア描画）のみ。
- **未確認**: Chrome/Edge（GPU）、Firefox、Safari（15 以降は WebGL 2 対応のはず）、iOS/Android。これらは「動くはず」であって、確認したとは言えません。確認手順は [TESTING.md](TESTING.md)。
- 動かないもの: `file://` から開く ES モジュール、WebGL 2 非対応環境、Blob Worker を禁止する CSP 下での Worker 物理（メインスレッドへフォールバック）。

## 物理
- 球と軸平行箱のみ。**物体は回転しません**（箱は常に軸に揃う）。
- 箱の積み上げは安定しません（スリープ・接触の継続情報がないため揺れます）。球の山や、床・壁への衝突は用途に合います。
- `PhysicsWorld` には連続衝突判定（CCD）がありません。高速で薄い物体はすり抜けます。`maxSpeed`（既定 100）と固定ステップで緩和しているだけです。CCD は検出専用の `CollisionWorld` の球にだけあります。
- ジョイント・拘束・凸形状・トリガー専用形状は未実装。
- 反発係数は 2 物体の小さい方、摩擦は単純なクーロン近似です。
- 物理の `raycast` は O(N)（総当たり）です。
- Worker 版は 1 フレーム遅れます。物体の追加は非同期（Promise）です。
- セル幅を物体より小さくすると総当たりになり急に遅くなります（Node 実測: 1 万個でセル幅 0.45 → 約 600 ms/ステップ、0.6 → 約 3 ms。警告が出ます）。

## 描画
- 影は先頭の影つき方向光 1 灯のみ。透明物体と `alphaTest` 物体は影を落としません。影の範囲は固定半径（`shadow.extent`）で、広い世界ではカメラ追従またはカスケードが必要です。
- 透明なインスタンスはメッシュ全体で 1 回ソートされ、インスタンス間のソートはされません。
- `static` サブツリーの内側を `markDirty()` なしで書き換えても反映されません。
- 点光源は影を落としません。
- GPU 時間は `EXT_disjoint_timer_query_webgl2` が使える環境のみ。SwiftShader では値が出ますがソフトウェア描画の時間で、実 GPU の値ではありません。`gpuMs` は取得が数フレーム遅れて届きます。
- `gpuBytes` はエンジンが作った GPU リソースの概算で、ブラウザが実際に確保した量ではありません。

## シーン JSON
- 物理状態は含みません（`world.toJSON()` を別途）。URL 由来のテクスチャは保存できず白で置換し警告します。

## その他
- 1 つの canvas に同時に 1 エンジン。
- `position.set(x,y,z)` は TypedArray の `set` で意図通りに動きません。`setPosition()` を使ってください。
- ライセンス未設定。

## 1.1 追加分の制限（CollisionWorld ほか）
- `CollisionWorld` は**検出専用**です。位置補正・反発・摩擦は行いません（`PhysicsWorld` とは別物で、自動連携もしません）。
- 接触点は 1 点だけ（面と面の接触の複数点は出ません）。カプセル×箱の深い貫入では深さが最小とは限りません。
- CCD: `continuous` は球のみ。掃引の相手は「現在位置にある静止物」として扱い、相手も高速で動く場合の正確な衝突時刻は出ません。`teleport()` は掃引しません。
- ブロードフェーズは `hash` / `tree` / `brute`。`tree` は全員が動き続ける大群には遅い（10 万体で約 1.2 秒/step）。`auto` は作成時点の内容で 1 回だけ選びます。
- ハンドルの index 上限は 4,194,304（2^22）。世代が 2^30 に達したスロットは退役し再利用しません。
- パーティクルは CPU 更新。容量を超える発生は捨てられ `overflow` に数えられます。
- 差分転送はチャンク内の「最小〜最大の変更範囲」を 1 本の連続範囲で送ります。離れた 2 箇所だけ更新すると間も送ります。
- オクルージョンカリングはフックのみ。デバッグ描画は 2D オーバーレイで深度テストがなく、物体の裏の線も見えます。
- 音声・タッチ・ゲームパッドは実機確認をしていません（偽のオブジェクトによる単体テストのみ）。
- GPU 時間はこの環境では SwiftShader のものしか見ておらず、実 GPU での値は未測定です。


## 1.2 追加分の制限（RigidBodyWorld）
- Hinge / Fixed / Motor / Limit 拘束は未実装。Distance / BallSocket は実験的でテストは各1件。
- 転がり/ねじり摩擦は未実装。`contactAngularDamping`（既定 1.0）の近似で、球・カプセルは後期でも眠らない個体が残りうる。
- 重心オフセット・複合形状・メッシュ・凸包・ハイトフィールドは未対応。カプセル×箱は近似マニフォールド。
- CCD は芯球近似。回転による貫通・細長い箱の側面・同時 TOI は保証しない。
- 10,000 体の動的な剛体は Node(2コア Xeon) で 1 ステップ約 10〜100 ms で、60 fps に収まらない。眠れば大幅に軽くなる（箱の塔は全員睡眠で 0.002 ms）。
- 決定性は同一エンジン・環境・操作列のみ。ブラウザ/CPU 間の一致は保証しない。
- 力・トルクは毎ステップクリア。スリープ中は接触終了イベントが出ない。
- GPU 時間は測っていない（剛体は CPU のみ）。
