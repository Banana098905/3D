# 剛体物理 `RigidBodyWorld`（1.2.0）

3D 剛体（回転・慣性・接触マニフォールド・逐次インパルス）。既存の `PhysicsWorld`（球のみ・粒子向け）と `CollisionWorld` は**変更せず並存**します。ゲーム固有の機能（AI・武器・ステージ等）は含みません。

## 使い方
```js
const engine = new Engine(canvas);
const w = engine.enableRigidBodyPhysics({ gravity: [0,-9.81,0], interpolate: true });
w.addBody({ type: 'static', shape: 'plane', normal: [0,1,0], offset: 0 });
const h = w.addBody({ shape: 'box', halfExtents: [.5,.5,.5], position: [0,5,0], mass: 2, node: mesh });
w.applyImpulseAtPoint(h, 0,3,0,  0.2,0,0);
// engine のループが advance() と Node 同期を行う。単体なら w.advance(realDt)
```
`RigidBodyWorld` は単体でも使えます（`import { RigidBodyWorld } from './src/index.js'`）。

## 実装状況
| 項目 | 状態 | 備考 |
|---|---|---|
| static / dynamic / kinematic / sensor / lockRotation（軽量） | 実装 | ハンドルは世代付き（`HandleAllocator`）。無効・削除済みは false/null を返す |
| 姿勢（クォータニオン）・角速度・トルク・ワールド慣性 | 実装 | 位置更新は指数写像で厳密。ジャイロ項は陰的（Catto 2015、Newton 1 回） |
| 慣性: 球・箱(OBB)・カプセル | 実装（解析解） | 一様密度。カプセルは円柱+半球の厳密式。**重心オフセット・複合形状は未対応** |
| 接触マニフォールド（最大4点・特徴ID・累積インパルス） | 実装 | 下記対応表。法線は a→b |
| ソルバ: 逐次インパルス、ウォームスタート、スプリットインパルス、反発しきい値、静/動摩擦 | 実装 | 摩擦の組合せは既定 √(a·b)（動摩擦は静摩擦以下に制限）、反発は max |
| CCD | **部分実装** | 下記「CCD の範囲」 |
| スリープ | 実装 | 接触でつながった島単位。閾値・時間はオプション。接触・力・インパルス・setPosition 等で起床 |
| 拘束 | **基盤+実験的** | `DistanceConstraint` / `BallSocketConstraint` のみ（テスト2件）。**Hinge / Fixed は未実装**（`addConstraint` に `prepare/solveVelocity` を持つオブジェクトを渡せる拡張フックのみ） |
| Node 同期 | 実装 | dynamic→Node、kinematic は Node の動きを速度化。Slerp 補間は描画用で物理状態を変えない。親から外された Node は自動解除 |
| 固定刻み | 実装 | accumulator・最大サブステップ・時間予算（`stepBudgetMs`）・pause/resume・timeScale・破棄時間 `droppedTime` |
| デバッグ描画 | 実装（既定 OFF） | `DebugDraw.rigidBodyWorld(w, {enabled:true})`: 形状・AABB・接触点・法線・深度・速度・角速度・重心・慣性・状態色 |
| 統計 | 実装 | `getStats()`。CPU 時間のみ（GPU 時間とは別） |

### 接触の対応表
球×球、球×箱、箱×箱（SAT 15軸+クリッピング）、箱×平面、球×平面、OBB×OBB（=箱×箱）、カプセル×{球,カプセル,箱,平面}。
**カプセル×箱は近似マニフォールド**（線分上の最近点＋端点）で、厳密な多点ではありません。平面は静的のみ（dynamic の平面は例外）。未対応の組合せは `onWarning` に警告し `stats.unsupportedPairs` に数えます（黙って無視しません）。

### CCD の範囲
- 対象: 高速（`ccdThreshold` 以上の移動量）の dynamic。TOI は**芯球**（球は厳密、箱・カプセルは最小半径で近似）を、スイープ AABB のクエリ結果と平面に当てて求める。
- TOI の位置で止め、残り時間は失い、接触は次ステップで解決する。TOI≈0 は無視（張り付き防止）。
- 回転による貫通、細長い箱の側面、複数物体の同時 TOI、動く物体どうしの正確な TOI は保証しない。

## 数値・規約
- 単位は SI（m・kg・s）。右手系、Y 上。
- 力・トルクは**ステップごとにクリア**される（持続力は毎フレーム与える）。
- 接触イベントは begin/end。スリープ中は end が出ず、起床直後に begin が再度出ることがある。
- `contactAngularDamping`（既定 1.0）: 接触中の物体に角減衰を足す**転がり/ねじり抵抗の近似**。転がり/ねじり摩擦そのものは未実装で、これが無いと球が空転し続けて眠れない。純粋な転がりを見たいときは 0 にする。
- 決定性: 同一エンジン・同一環境・同一操作列で `stateHash()` が一致することをテストで確認。**異なるブラウザ/CPU/JIT 間の一致は保証しない**（浮動小数点・Math 関数の差）。

### ブロードフェーズ 'auto' の閾値
`bench/rigid-broadphase-threshold.mjs` で総当たり/ハッシュ/ツリーを比較（`bench/results/rigid-broadphase-threshold-v1.2-node.json`）。交差は 48〜96 体付近で、差は 0.03 ms 未満。`bruteForceThreshold: 24` は保守的で実害のない値のため据え置き。

## 既知の制限
- 重心オフセット・複合形状・メッシュ/凸包・ハイトフィールド: 未対応。
- 転がり/ねじり摩擦、拘束の Hinge/Fixed/Motor/Limit: 未実装。
- カプセル×箱は近似マニフォールド。CCD は上記の近似。
- 大質量比（≥100:1）の積み上げは反復回数を増やさないと沈み込む場合がある（未系統測定）。
- WebGPU・GPU 物理・ソフトボディ・流体・破壊は範囲外。

## テスト
