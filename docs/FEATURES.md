# 実装済み／未実装の機能一覧

凡例: ✅ 実装し、テストで確認済み ／ 🟡 実装済みだが確認範囲が限定的 ／ ❌ 未実装

## レンダラー
| 機能 | 状態 | 備考 |
|---|---|---|
| シーングラフ（親子変換）、Group | ✅ | 単体テスト |
| 透視／正投影カメラ | ✅ | ブラウザテストで画像が変わることを確認 |
| Box / Sphere / Plane / Cylinder / カスタム Mesh / インデックス付き | ✅ | 面の向き（外向き）を単体テストで検証 |
| UV・法線・頂点カラー | ✅ | 法線の自動計算あり |
| マテリアル、テクスチャ（データ・canvas・URL・チェッカー） | ✅ | URL は参照カウント＋キャッシュ |
| 環境光／方向光／点光源（Blinn-Phong） | ✅ | 方向光 2 灯・点光源 8 灯まで |
| シャドウマッピング（1 灯、3×3 PCF） | ✅ | 影の ON/OFF で画像差を確認。カスケードなし |
| 透明描画・深度テスト | ✅ | 半透明は後ろから前へソート。インスタンスは全体で 1 ソート |
| インスタンシング | ✅ | 10 万個で描画コール 25（チャンク 4096） |
| レイキャスト／ピッキング | ✅ | インスタンスの `instanceId` も返す |
| リサイズ・高 DPI | ✅ | |
| WebGL コンテキスト喪失／復元 | ✅ | CPU 側データから自動再作成、復元後に自動再開 |
| アセットの作成・登録・解放 | ✅ | `AssetManager` |
| WebGPU | ❌ | 未実装。将来のバックエンド分離のためレンダラーを `renderer.js` に隔離している**だけ**です |
| ポストエフェクト、スケルタルアニメ、glTF 読み込み、スカイボックス | ❌ | |

# 1.1 で追加した機能（仕様書の区分に沿った状況表）
凡例: ✅ 実装＋テスト済み ／ 🟡 部分実装（制限あり）／ ❌ 未実装

## 衝突判定（`CollisionWorld` — 検出専用。位置の補正・力の適用はしない）
| 機能 | 状態 | 備考 |
|---|---|---|
| 形状: 球 / AABB / OBB / カプセル / 平面 / レイ | ✅ | 閉形式。独立実装の GJK・サポート関数・レイマーチと照合（不一致 0） |
| 接触情報（接触点・法線・深さ）、ちょうど接する場合は非衝突 | 🟡 | 接触点は 1 点のみ。カプセル×箱の深い貫入の深さは最小保証なし |
| 広域: 総当たり(基準) / 空間ハッシュ / 動的 AABB ツリー(BVH 相当) | ✅ | 総当たりとの完全一致を 7 シーン（追加・削除・移動・無効化込み）で検証 |
| 広域: SAP（Sweep and Prune） | ❌ | 未実装 |
| 静的 BVH の一括再構築（SAH 等） | ❌ | 動的ツリーの逐次挿入のみ |
| イベント: 開始/継続/終了、トリガー、レイヤー/マスク | ✅ | 順序は広域方式に依存せず決定的（ソート） |
| CCD: 球の連続判定（掃引球・線分・平面・箱・カプセル相手、TOI） | 🟡 | `continuous` は**球のみ**。相手は現在位置で静止とみなす。箱/カプセル自身の連続判定は未対応 |
| 空間クエリ: レイ（最近/全部）、AABB、半径、掃引球 | ✅ | |
| ハンドル（世代付き）、一括追加/削除/更新、スロット再利用 | ✅ | 古いハンドルは必ず無効。10 万回の生成削除でメモリ増なし |
